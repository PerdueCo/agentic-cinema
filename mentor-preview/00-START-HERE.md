# Agentic Studio Digital Twin — Mentor Preview Package

## Purpose

This package gives a busy mentor one clear place to understand the project without searching through the entire repository.

The story is presented honestly as an evolution:

1. **Original vision:** a broad twelve-agent autonomous movie studio.
2. **Scene 42 prototype:** a weather disruption, production-risk analysis, human approval, and Digital Twin update.
3. **Current September 7 MVP:** four working agent roles—Research, Scheduling, Budget, and Producer—being connected into one end-to-end workflow.

## What is included

| File | Purpose |

| `index.html` | The single mentor-facing preview page |
| `assets/01-scene-42-target-experience.png` | Target product experience and Scene 42 storyboard |

The earlier twelve-agent brainstorm trailer remains online as optional background:

https://perdueco.github.io/agentic-cinema/digital-twin-trailer/

## Important labels

- The concept image is a **target product experience**, not proof that every displayed technology is implemented.
- The four-second video is a **generated cinematic concept shot**, not application footage.
- The screen recording is an **interactive interface prototype using simulated presentation data**, not yet the live four-agent backend.
- The current coded MVP uses **Research, Scheduling, Budget, and Producer** agents.
- Physics and Safety remain future extensions or analysis categories; they are not additional September MVP agents.

## Add this package to GitHub

1. Open your local `Agentic-Cinema` project folder.
2. Copy the entire `Agentic-Studio-Mentor-Preview` folder into it.
3. Rename the copied folder to `mentor-preview`.
4. Commit and push the new folder to the `main` branch.
5. After GitHub Pages updates, open:

   `https://perdueco.github.io/agentic-cinema/mentor-preview/`

6. Test the image, both local videos, the brainstorm-trailer link, and the GitHub link.
7. Send the mentor only the preview-page link using `MENTOR-MESSAGE.txt`.

## Mentor review path

The page is intentionally organized in two levels:

- **Quick review:** project statement, current four-agent scope, concept image, and four-second concept shot.
- **Optional deeper review:** the 3:41 interface walkthrough, original twelve-agent trailer, and source repository.

This keeps the first review brief while preserving the supporting material.
